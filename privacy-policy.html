Priora Privacy Policy

Effective date: August 16, 2026  ·  Contact: priorashopify.app@gmail.com

This policy describes what data Priora ("the App," "we," "us") accesses when a merchant connects their Shopify store, and what happens to that data.

1. What Priora is

Priora is a Chrome browser extension that scans a merchant's Shopify product catalog and generates a prioritized list of data-quality and SEO issues (such as missing alt text, missing meta descriptions, or placeholder product titles), so the merchant can decide what to fix first.

2. What data we access, and why

When a merchant connects their store, Priora requests the following Shopify Admin API scopes:

  • read_products
  • read_product_listings

These scopes allow Priora to read product data — titles, descriptions, images, variants, and SEO fields — for the purpose of scanning it and generating a report. Priora does not request access to customer data, orders, payment information, or any personally identifiable information about a merchant's customers.

3. Where your data actually goes — the important part

This is the core of how Priora is built, and it's worth stating plainly:

Product data is scanned entirely inside your own browser. When you run a scan, the extension fetches your product catalog directly from Shopify's API and processes it locally, on your own machine, inside the extension. Priora does not transmit your product catalog to, or store it on, any server we operate. We have no database of merchant product data, because none is ever sent to us.

The only thing our server touches is the initial connection process (see Section 4) — never your ongoing product or store data.

4. What our backend server does handle

To connect your store, Shopify requires an OAuth authorization process that involves a small server component. Specifically, our backend:

  • Receives a one-time authorization code from Shopify after you approve access
  • Exchanges that code for an access token, using credentials that must never be exposed in browser-based code
  • Temporarily holds that access token — in server memory only, not a persistent database — long enough for your browser extension to retrieve it via a short-lived, one-time connection code
  • Deletes the connection code immediately after it's used, and automatically expires unused codes after 10 minutes

After this initial handoff, your access token lives only in your own browser's local extension storage (chrome.storage.local), which is not accessible to us, to other websites, or to other extensions.

5. Data retention

  • Product/catalog data: never stored by us, at any point, since it never leaves your browser.
  • Access tokens: held briefly in server memory during the connection process only, then only your browser retains the token going forward.
  • Connection codes: automatically deleted after first use or after 10 minutes, whichever comes first.

If our server is restarted, all in-memory data (pending connections, unused codes) is cleared automatically, since nothing is written to a persistent database.

6. Uninstalling

If you uninstall Priora or disconnect your store, your access token stored in the browser is removed. If you'd like us to confirm no residual data exists on our side, contact us at the address above — given the architecture described above, there generally won't be any, since we don't retain product or store data after the connection step completes.

7. GDPR and data subject requests

Because Priora does not access, process, or store customer personal data, and does not retain merchant product data after processing, our webhook endpoints for data requests, customer redaction, and shop redaction are implemented as required by Shopify, and will confirm no relevant data is held wherever that is the case.

8. Changes to this policy

If how Priora handles data changes in the future — for example, if we later add server-side features — we will update this policy and note the change, since the description above is only accurate for the architecture as currently built.

9. Contact

Questions about this policy or your data can be sent to priorashopify.app@gmail.com.
